System check

System diagnostics

Check the local calculation engine separately from the external data services. Local calculations do not require a network connection.

Local applicationNo network required
Public data servicesLive browser requests

Run these checks from the Vite development server. Exoplanet Archive requests use the local development proxy; the other providers are contacted directly. A failed request can indicate a provider outage, rate limit, or network problem.

Six service checks are available. Launch Library limits unauthenticated requests, so avoid rerunning checks repeatedly.

How to read the results

Local calculations pass, API checks fail: the calculator engine is working; investigate external service access.

Local calculations fail: investigate JavaScript startup or the local physics module before changing API settings.

An external service fails: inspect the browser console and Network tab. Do not add an untrusted CORS proxy or place private credentials in frontend code.
